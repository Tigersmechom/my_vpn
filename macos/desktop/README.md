# Полный рабочий стол сервера

В My VPN 1.3.0 кнопка **«Рабочий стол США»** открывает отдельное окно с полным
сеансом Ubuntu/XFCE. В нём есть Firefox, файловый менеджер, терминал и панель
приложений. Браузер выполняется на сервере, а Mac передаёт изображение и ввод.
Закрытие окна отключает просмотр; программы на сервере продолжают работать.
VPN-подключение для открытия рабочего стола не обязательно, если SSH доступен напрямую.

Используются [TigerVNC](https://github.com/TigerVNC/tigervnc),
[noVNC](https://github.com/novnc/noVNC) и WebKit. VNC слушает `127.0.0.1:5901`,
noVNC — `127.0.0.1:6080`. Внешнее соединение — SSH с проверкой закреплённого
ключа сервера. Отдельный SSH-пользователь может только перенаправлять локальный
порт noVNC; интерактивный SSH и перенаправление других портов запрещены.
Графический сеанс работает от обычного пользователя, без прав root.

Временная папка и системные файлы службы изолированы. Сеанс ограничен 1,4 ГБ RAM,
его приоритет CPU ниже VPN. Для VPS с 2 ГБ RAM добавлено 2 ГБ swap. Такой сервер
подходит для нескольких обычных вкладок; тяжёлые сайты могут работать медленно.

На Mac ключ и пароль находятся вне приложения:
`~/Library/Application Support/MyVPN/Desktop/identity` и `access.json`, права 600.
Приложение не содержит административный SSH-ключ. На настроенном Mac кнопка
работает сразу; переустановка приложения не удаляет доступ.

Для другого Mac используйте приватный архив `MyVPN-Desktop-access-private.zip`:
распакуйте его и выполните `bash install-access.sh` из папки архива. Этот архив
даёт доступ к рабочему столу и данным браузера; он не публикуется в GitHub.

На сервере установка:

```bash
VNC_PASSWORD_FILE=/root/private/vnc-password SSH_PUBLIC_KEY_FILE=/root/private/desktop-key.pub bash server/desktop/install.sh
```

Пароль VNC — восемь случайных ASCII-букв/цифр в приватном файле; закрытый
SSH-ключ остаётся на Mac. Установщик проверяет ключ репозитория Mozilla перед
установкой Firefox. Он не перезапускает VPN-службы.

Обслуживание:

```bash
systemctl status myvpn-desktop myvpn-desktop-web
systemctl restart myvpn-desktop myvpn-desktop-web
```

Перезапуск графического сеанса завершает открытые программы. После изменения
HTML достаточно заново открыть окно просмотра. Для отключения постоянного
графического сеанса: `systemctl disable --now myvpn-desktop-web myvpn-desktop`.
