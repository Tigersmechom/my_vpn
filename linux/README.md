# My VPN для Ubuntu 24.04

Собственное приложение GTK для Ubuntu Desktop 24.04, Intel/AMD (amd64).
Девять режимов текущего персонального профиля: VLESS REALITY/Vision, Hysteria 2,
Hysteria 2 + Salamander, AmneziaWG и пять дополнительных режимов Xray.

## Установка

В каталоге со скачанным пакетом:

```bash
sudo apt install ./MyVPN-1.2.0-ubuntu24.04-amd64.deb
```

Откройте **My VPN** в меню приложений. Выберите режим и нажмите «Подключить».
Ubuntu запросит пароль администратора для настройки сетевого интерфейса.
Приложение при установке не включает VPN и не добавляет автоподключение.
Для Ubuntu Server без графического окружения этот пакет не предназначен.

Кнопка **«Обновить конфигурацию»** загружает и проверяет зашифрованный профиль.
Новый сервер или совместимый режим появится без переустановки. При работающем
VPN изменения применяются после следующего подключения. Новое исполняемое ядро
или новый протокол, которого нет в Xray, требуют новой версии приложения.
Если действующий сервер перестал отвечать и обновление не загружается, сначала
отключите VPN: загрузка обновлений использует текущий системный маршрут.

Статус «Туннель запущен» означает запуск сетевого компонента. Кнопка проверки
соединения отдельно проверяет HTTPS и передачу 64 КиБ. При проблемах попробуйте
VLESS XHTTP, затем другие режимы. Shadowsocks 2022 в текущем профиле — резерв.

Пакет персональный и содержит секреты доступа. Не публикуйте его. В публичном
GitHub находятся только исходники и зашифрованный `updates/linux.json`.
Профиль Linux имеет отдельные ключ и адрес AmneziaWG; Mac и Ubuntu могут
подключаться одновременно. Учётные данные режимов Xray общие с Mac.

## Сетевой компонент

GUI работает от обычного пользователя. Только фиксированный helper через polkit
управляет службой `myvpn-client.service`. Конфигурация ограничена проверяемой схемой;
команды, пути к файлам и скрипты из профиля не исполняются. Служба использует собственный
TUN, маршруты и DNS `systemd-resolved`. Во время подключения IPv6 закрывается, чтобы
он не обходил туннель IPv4. Отключение удаляет настройки этого приложения.
Используйте один системный VPN на компьютере за раз.

Восстановление после закрытия окна: снова откройте приложение и нажмите «Отключить».
При необходимости это можно сделать из терминала:

```bash
pkexec /usr/lib/myvpn/myvpn-helper stop
```

## Сборка

На Ubuntu 24.04 установите Python 3, `python3-cryptography`, Go, git, curl, unzip,
gcc, make и libc6-dev. Подготовьте `config/linux.json` и `config/linux-update.json`.
Если личного профиля нет, используется фиктивный `config/example.json`.

```bash
./linux/fetch-cores.sh
python3 linux/build.py --arch amd64
```

`build.py` может собрать пакет и на macOS, если Linux ELF-файлы уже подготовлены
в `linux/vendor/amd64/`. Он не устанавливает пакет и не настраивает сеть.
Версии ядер совпадают с Android/macOS: Xray v26.9.30, AmneziaWG-Go
v3.1.20260828, AmneziaWG Tools v1.0.20260618-2. В пакет входят их лицензии.

Проверки логики и GTK (через виртуальный дисплей):

```bash
PYTHONPATH=linux python3 -m unittest discover -s linux/tests -v
PYTHONPATH=linux xvfb-run -a python3 -m unittest discover -s linux/tests -p 'test_gui.py' -v
```

Тесты маршрутизации используют подмену системных команд. Они не включают VPN
хоста. Для настоящих TUN-проверок используйте отдельную VM или network namespace.

Сборка 17 октября 2026 проверена в Ubuntu 24.04: установка `.deb`, запуск GTK
от обычного пользователя, 55 проверок логики и интерфейса. В отдельных сетевых
пространствах проверены настоящие TUN Xray/AmneziaWG, очистка после сбоя и передача
64 КиБ через Hysteria 2 с проверкой содержимого. TUN-проверки также прошли с
ограничениями systemd-службы. Проверка трафика использовала локальный тестовый
сервер; доступность каждого режима в сети конкретного пользователя этим не гарантируется.

## Отдельный профиль Linux на существующем сервере

Следующая команда создаёт отдельный AWG peer и сразу добавляет его в работающий
интерфейс. Xray и AmneziaWG не перезапускаются, остальные peers не изменяются:

```bash
vpnctl add-awg-device linux mac
vpnctl profile linux > /root/linux-base.json
```

Основные ключи Xray наследуются от `mac`. Скопируйте `extraXray` из полного профиля
Mac в Linux-профиль, сохранив отдельную секцию `awg` и `client: "linux"`.
Такие peers хранятся в `/etc/myvpn/awg-devices/`; последующие `vpnctl render`
сохраняют их в AmneziaWG, не дублируя пользователей Xray.
`vpnctl remove linux` удаляет только отдельный AWG peer, без перезапуска служб.
Общие ключи Xray отзываются при удалении основного клиента Mac.

После подготовки нового Linux-профиля опубликуйте обновление, сохраняя bootstrap:

```bash
.venv/bin/python tools/publish_updates.py --profile config/linux.json --bootstrap config/linux-update.json --output updates/linux.json
git add updates/linux.json
git commit -m "Update encrypted Ubuntu profile"
git push origin main
```

Для первой публикации дополнительно задайте `--init-url` с HTTPS-адресом
`https://raw.githubusercontent.com/OWNER/REPO/refs/heads/main/updates/linux.json`.
